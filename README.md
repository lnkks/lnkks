# 个人主页

一个简单的个人展示页面，使用 HTML + CSS 构建。

## 关于这个仓库

这是我学习 Git 和 GitHub 的练习项目，代码本身没有技术含量。

如果你点进来了——**不建议花时间阅读**，这里只有 Git 新手练手的 commit 记录。

## 技术栈

- HTML
- CSS（浅色/深色双主题）

## 学到了什么

从零开始用 17 次 commit 搭建页面，过程中练习了：

- Git 基础（init、add、commit、status、log）
- 分支操作（branch、switch、merge --no-ff）
- 撤销操作（reset --soft、reset --hard、revert）
- 历史改写与隐私保护（filter-branch、force push）
- SSL 配置与远程推送排错
